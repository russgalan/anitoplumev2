# Thesis Scope

## Research Objectives

1. Benchmark GPU resource synchronization and
   cross-API shader translation.

2. Redesign AnitoPlume using an explicit
   graphics architecture.

3. Compare rendering efficiency between
   the legacy and modernized pipelines.

4. Evaluate usability with target users.

## Scope

The study ports AnitoPlume from OpenGL
to a modern explicit graphics API.

The existing Lagrangian plume simulation
model is preserved.

Changes to the underlying volcanic physics
are outside the scope.
